# Galgyo Desktop Pet

This is a Galgyo-specific Windows desktop pet modeled after the KIMACHI desktop-pet implementation.

The app includes directional running, waving, jumping, sad, asking, thinking, sitting, hover-action selection, resize, always-on-top, position locking, and saved settings.

The character is an unofficial, non-commercial derivative character inspired by Winter. It is not affiliated with or endorsed by aespa, Winter, SM Entertainment, or any rights holder.
