KIMACHI Desktop Pet for Windows
===============================

Kimachi is Kim Chaewon's representative character: a brave, focused,
and slightly tsundere golden baby cheetah.

How to use
----------
1. Double-click KIMACHI.exe.
2. Left-drag KIMACHI to move her. Dragging left or right automatically
   plays the matching directional running animation.
3. Double-click Kimachi to make her wave.
4. Right-click KIMACHI to change her animation or settings.
5. Use "Hover Action" to choose what she does when the mouse moves over her.
6. Use "Resize..." for continuous scaling from 50% to 200%.
7. Select "Quit" from the right-click menu to close the program.

Codex and Python are not required.

Windows may show a SmartScreen warning because this personal app is not
code-signed. Choose "More info" and "Run anyway" only if you received this
file from a trusted source.
